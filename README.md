## Share with the team

1. Open **Settings → Pages** on this repo: https://github.com/samselwyn85/stride/settings/pages
2. Set source to **GitHub Actions** (preferred) or **Deploy from a branch** → `main` / root.
3. Wait one minute, then send:

- Home: https://samselwyn85.github.io/stride/
- Journey: https://samselwyn85.github.io/stride/app.html
- Cited demo: https://samselwyn85.github.io/stride/stride-demo-rcrsp-nz.html

On phone: open the home link → Share / Add to Home Screen.
